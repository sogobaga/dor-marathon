# DORPG 防具表 v1

資料來源：`scratchpad/dorpg_p8/armor_all.json`（已通過 `validate_armor.py` 全部規則，0 錯誤）。

- 防具總數：390 件（六職業 × 五部位 × 10 級＝300 ＋ 通用飾品 18 效果 × 5 級＝90）
- 五部位（頭盔／手套／衣服／褲裙／鞋子）**每個職業各有一套專屬**，數值依職業係數不同；飾品**六職業通用**，不分職業皆可裝備
- 等級門檻＝Tier 對應 1/10/20/30/40/50/60/70/80/90（防具）；飾品 t1 Lv1／t2 Lv20／t3 Lv40／t4 Lv60／t5 Lv80
- 稀有度：防具 common(t1–3)／rare(t4–6)／epic(t7–9)／legendary(t10)；飾品 common(t1)／rare(t2–3)／epic(t4)／legendary(t5)

## 規則摘要（契約 §2／§3）

### §2 ArmorProfile 欄位（缺省＝中性）

```
{ def, str, agi, vit, dex, int, luk,
  hp_pct, mp_pct, atk_pct, matk_pct,
  interval_pct,        // 負＝攻擊間隔縮短（與武器 interval_pct 相加）
  crit_pct, crit_dmg_pct,
  mp_cost_reduce_pct,  // 技能 MP 消耗 ×(1−pct/100)，floor，下限 1
  hp_regen_pct_per_5s, // 每 5 秒回復 HPMax 的 n%（floor，戰鬥中持續）
  mp_regen_pct_per_5s,
  damage_taken_pct,    // 負＝少受傷（與 buff 相加）
  element_resist_pct } // 與武器（鍊）相加
```

彙總規則（`AggregateEquipment`）：六素質 flat 相加；def flat 相加；hp_pct／mp_pct／atk_pct／matk_pct／crit_pct／crit_dmg_pct 相加；interval_pct 相加後 clamp ≥ −50；element_resist_pct 相加後 clamp ≤ 60；damage_taken_pct 相加後 clamp ≥ −60；mp_cost_reduce_pct clamp ≤ 50；regen 相加。

### §3 數值規則

- 基礎防具總 DEF(t) = round(RefDef(L) × 0.5)，分配 衣服 35%／褲裙 25%／頭盔 15%／手套 12.5%／鞋子 12.5%，再乘職業 DEF 係數，每件 `max(1, round(...))`。
- 副屬性基礎（t1→t10 線性）：衣服 vit 1→8、hp_pct 2→12；褲裙 vit 1→6、hp_pct 1→8；頭盔 int 1→8；手套 str 1→8；鞋子 agi 1→5、dex 1→5；再乘職業副屬性係數，四捨五入，`max(1, …)`。
- 飾品 18 種效果 × 5 級＝90 件，通用（job_id＝null）；每種效果 t1→t5 線性遞增（詳見下方飾品表）。
